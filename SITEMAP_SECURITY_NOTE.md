# Sitemap Security Note

## Custom Sitemap Filename: `sitemap-ntw2024.xml`

### Why Custom Name?
- **Competitive Intelligence**: Hides your sitemap from easy discovery
- **Security Through Obscurity**: Makes it harder for competitors to analyze your site structure
- **Less Bot Traffic**: Many scrapers only look for standard "sitemap.xml" files

### Access
- **Public URL**: `https://naqashthaheem.com/sitemap-ntw2024.xml`
- **Via robots.txt**: Properly referenced for search engines
- **Google Search Console**: Submit this specific URL

### Best Practices
1. Don't publicly link to this sitemap
2. Only submit to legitimate search engines
3. Keep the filename unique but memorable
4. Update the filename periodically for additional security

### Remember
- The "ntw" stands for Naqash Thaheem Workflows
- Year "2024" makes it easy to identify
- Search engines will still find it via robots.txt
- This prevents casual snooping without affecting SEO
